រូបមន្តដឺម័រ (De Moivre's Theorem)

ចំពោះគ្រប់ចំនួនគត់ធម្មជាតិ $n$៖

$$(\cos\theta + i\sin\theta)^n = \cos n\theta + i\sin n\theta$$

ស្វ័យគុណទី $n$ នៃចំនួនកុំផ្លិចទូទៅ

បើ $z = r(\cos\theta + i\sin\theta)$ នោះពេលលើកជាស្វ័យគុណទី $n$៖

  • ម៉ូឌុល $r$ ត្រូវលើកស្វ័យគុណ $n$ ($r \rightarrow r^n$)
  • អាគុយម៉ង់ $\theta$ ត្រូវគុណនឹង $n$ ($\theta \rightarrow n\theta$)
$$z^n = r^n(\cos n\theta + i\sin n\theta)$$

ស្រាយបញ្ជាក់រូបមន្តដឺម័រ (តាមវិចារកំណើនគណិតវិទ្យា)

ជំហាន 1 / 3
១. ពិនិត្យ៖ ឲ្យ $n=1$, គេបាន $(\cos\theta + i\sin\theta)^1 = \cos\theta + i\sin\theta$ (ពិត)។
២. សន្មតថាពិតដល់ $k$៖ $(\cos\theta + i\sin\theta)^k = \cos k\theta + i\sin k\theta$ (ពិត)។
៣. បង្ហាញថាពិតដល់ $k+1$៖
$(\cos\theta + i\sin\theta)^{k+1} = (\cos k\theta + i\sin k\theta)(\cos\theta + i\sin\theta)$
$= (\cos k\theta\cos\theta - \sin k\theta\sin\theta) + i(\sin k\theta\cos\theta + \cos k\theta\sin\theta) = \cos(k+1)\theta + i\sin(k+1)\theta$
ដូចនេះ រូបមន្តពិតចំពោះគ្រប់ $n \in \mathbb{N}^*$ ។
