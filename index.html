ចំនួនកុំផ្លិចទម្រង់ត្រីកោណមាត្រ

ស្វ័យគុណទី $n$ និងរូបមន្តដឺម័រ (De Moivre's Theorem)

ស្វាគមន៍មកកាន់
មេរៀនចំនួនកុំផ្លិច

វត្ថុបំណងមេរៀន៖

  • ពន្យល់ និងកំណត់ស្វ័យគុណទី $n$ នៃចំនួនកុំផ្លិចក្នុងទម្រង់ត្រីកោណមាត្រ។
  • ប្រើប្រាស់ រូបមន្តដឺម័រ (De Moivre) បានត្រឹមត្រូវ។
  • គណនាស្វ័យគុណ និងបម្លែងលទ្ធផលទៅទម្រង់ $a+bi$ បានស្ទាត់ជំនាញ។

សូមប្រើប្រាស់ម៉ឺនុយខាងលើដើម្បីចាប់ផ្តើមការសិក្សា លំហាត់គំរូ និងការអនុវត្តជាក់ស្តែង។

រូបមន្តស្នូល និងទ្រឹស្តីបទ

ដំណាក់កាលទី៣ ៖ ការរកឃើញទម្រង់នៃ $z^n$

ឲ្យ $z = r(\cos\theta + i\sin\theta)$ ។ ប្រើរូបមន្តផលគុណ $z_1z_2 = r_1r_2[\cos(\theta_1+\theta_2) + i\sin(\theta_1+\theta_2)]$ ៖

ស្វ័យគុណ លទ្ធផល
$z^2 = z \cdot z$ $r^2(\cos 2\theta + i\sin 2\theta)$
$z^3 = z^2 \cdot z$ $r^3(\cos 3\theta + i\sin 3\theta)$
$z^4 = z^3 \cdot z$ $r^4(\cos 4\theta + i\sin 4\theta)$
ការសន្និដ្ឋាន

ម៉ូឌុលត្រូវលើកស្វ័យគុណ $n$ ហើយអាគុយម៉ង់ត្រូវគុណនឹង $n$ ៖
$z^n = r^n(\cos n\theta + i\sin n\theta)$

រូបមន្តដឺម័រ (De Moivre)

ចំពោះគ្រប់ចំនួនគត់ធម្មជាតិ $n$៖

$$(\cos\theta + i\sin\theta)^n = \cos n\theta + i\sin n\theta$$

ស្វ័យគុណទី n នៃចំនួនកុំផ្លិចទូទៅ

បើ $z = r(\cos\theta + i\sin\theta)$ នោះពេលលើកជាស្វ័យគុណទី $n$៖

  • ម៉ូឌុល $r$ ត្រូវលើកស្វ័យគុណ $n$ ($r \rightarrow r^n$)
  • អាគុយម៉ង់ $\theta$ ត្រូវគុណនឹង $n$ ($\theta \rightarrow n\theta$)
$$z^n = r^n(\cos n\theta + i\sin n\theta)$$

ស្រាយបញ្ជាក់រូបមន្តដឺម័រ (តាមវិចារកំណើនគណិតវិទ្យា)

  • ១. ពិនិត្យ៖ ឲ្យ $n=1$, គេបាន $(\cos\theta + i\sin\theta)^1 = \cos\theta + i\sin\theta$ (ពិត)។
  • ២. សន្មតថាពិតដល់ $k$៖ $(\cos\theta + i\sin\theta)^k = \cos k\theta + i\sin k\theta$ (ពិត)។
  • ៣. បង្ហាញថាពិតដល់ $k+1$៖
    $(\cos\theta + i\sin\theta)^{k+1} = (\cos k\theta + i\sin k\theta)(\cos\theta + i\sin\theta)$
    $= (\cos k\theta\cos\theta - \sin k\theta\sin\theta) + i(\sin k\theta\cos\theta + \cos k\theta\sin\theta)$
    $= \cos(k+1)\theta + i\sin(k+1)\theta$
    ដូចនេះ រូបមន្តពិតចំពោះគ្រប់ $n \in \mathbb{N}^*$។

ការបកស្រាយធរណីមាត្រ

ឲ្យ $z = \cos\theta + i\sin\theta$ (មាន $r=1, \text{មុំ } \theta$)។ តាមរូបមន្តដឺម័រ៖

$z^k = \cos k\theta + i\sin k\theta$
សង្កេត៖ រាល់ការគុណនឹង $z$ មួយដង ចំណុចរូបភាពវិលជុំវិញគល់ $O$ មួយមុំ $\theta$ (ដោយម៉ូឌុលរក្សាតម្លៃនៅដដែល)។

ករណីស្វ័យគុណអវិជ្ជមាន

រូបមន្តដឺម័រក៏ពិតចំពោះស្វ័យគុណ $n \in \mathbb{Z}$ (អវិជ្ជមាន) ផងដែរ៖

$$(\cos\theta + i\sin\theta)^{-n} = \cos n\theta - i\sin n\theta$$

ឧទាហរណ៍៖ $(\cos\frac{\pi}{6} + i\sin\frac{\pi}{6})^{-2} = \cos\frac{\pi}{3} - i\sin\frac{\pi}{3}$

របៀបដោះស្រាយមួយជំហានម្តងៗ

ឧទាហរណ៍៖ ចូរគណនា $(1+i)^6$ រួចសរសេរលទ្ធផលជាទម្រង់ $a+bi$ ។

១

បម្លែង $z$ ទៅទម្រង់ត្រីកោណមាត្រ

តាង $z = 1+i$ ។ យើងត្រូវរកម៉ូឌុល $r$ និងអាគុយម៉ង់ $\theta$ ។

$r = \sqrt{1^2 + 1^2} = \sqrt{2}$
$\cos\theta = \frac{a}{r} = \frac{1}{\sqrt{2}}$ និង $\sin\theta = \frac{b}{r} = \frac{1}{\sqrt{2}}$ $\Rightarrow \theta = \frac{\pi}{4}$

ដូចនេះទម្រង់ត្រីកោណមាត្រគឺ៖ $z = \sqrt{2}(\cos\frac{\pi}{4} + i\sin\frac{\pi}{4})$
២

អនុវត្តរូបមន្តដឺម័រ (លើកស្វ័យគុណ n=6)

យក $r$ ស្វ័យគុណ ៦ និងយក $\theta$ គុណនឹង ៦។

$(1+i)^6 = \left[ \sqrt{2}(\cos\frac{\pi}{4} + i\sin\frac{\pi}{4}) \right]^6$

$= (\sqrt{2})^6 \left( \cos\frac{6\pi}{4} + i\sin\frac{6\pi}{4} \right)$
$= 8 \left( \cos\frac{3\pi}{2} + i\sin\frac{3\pi}{2} \right)$
៣

សរសេរលទ្ធផលចុងក្រោយ (ទម្រង់ $a+bi$)

គណនាតម្លៃនៃមុំត្រីកោណមាត្រដែលទទួលបាន។

ដោយ $\cos\frac{3\pi}{2} = 0$ និង $\sin\frac{3\pi}{2} = -1$

គេបាន៖ $= 8 (0 + i(-1))$
ចម្លើយចុងក្រោយ៖ $= -8i$
